## 1. 프로젝트 개요

### 1.1. 작업 배경

본 포트폴리오는 프론트엔드 개발자 조효희의 학습과 성장의 과정을 담은 프로젝트 모음집으로,
그동안 진행한 웹 리디자인 작업들을 체계적으로 정리하고,
디자인 감각과 퍼블리싱 능력을 종합적으로 보여주기 위해 제작되었습니다.

또한 방문자가 쉽고 빠르게 프로젝트 내용을 확인할 수 있도록
심플하고 직관적인 UI로 구성하였으며,
브랜드 감성과 일관된 톤앤매너를 유지하는 데 중점을 두었습니다.

이번 포트폴리오의 제작 목적은 다음과 같습니다:

* 각 프로젝트의 핵심 내용을 카드 형태로 정리해 한눈에 보기 쉽게 구성
* 반응형 웹 구현을 통해 다양한 디바이스에서 최적의 사용성 제공
* 자기소개, 이력, 프로젝트, 후기로 이어지는 흐름 있는 구조



### 1.2. 키워드

* 카드형 콘텐츠 구조를 통한 정보 전달의 명확성
* 반응형 웹 디자인으로 다양한 기기 최적화
* 포근하고 따뜻한 브랜드 감성 UI/UX
* 개인 이력과 프로젝트를 하나로 엮은 자기소개형 포트폴리오
* 개발자이자 디자이너로서의 정체성을 드러내는 시각적 연출
